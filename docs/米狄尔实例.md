# 实例：吞噬黑暗的米狄尔


把一场战斗从头读到尾，作为 [阅读方法.md](阅读方法.md) 里那套方法的示范。下面每个数字都来自
本仓库里的 `scripts/m51_00_00_00/621100_battle.lua`（深坑那场；桥上是 `scripts/m51_00_00_00/621000_battle.lua`）。动画号是原始号，
本文故意不给招式取名。

## 它在哪

```
NpcThinkParam 621100  "Darkeater Midir"
  battleGoalId 621100  ->  m51_00_00_00/621100_battle.lua   （注册为 GOAL_DarknessDragon621100_Battle）
  logicId      10000   ->  aicommon/010000_logic.lua        （巡逻用，只把战斗 goal 挂上去）
```

没有 `Switch`、没有第二形态脚本：一份文件、25 个 `Act`、30 个不同动画号。
动画和行为图在 `chr/c6211.*`（chr 号 = 621100 / 100）。

## 权重表

`Goal.Activate` 读距离、垂直距离、血量比例、事件请求值，以及
`IsInsideTargetRegion(TARGET_SELF, 5102880)`，然后填 `w[act]`：

| 距离 | 一阶段 | 二阶段（有 `16581`） |
|---|---|---|
| > 17 m | `w[2]=4  w[3]=7  w[7]=3  w[24]=4` | `w[1]=6  w[7]=1  w[22]=10  w[24]=4` |
| 8.5–17 m | `w[3]=5  w[6]=4  w[7]=6  w[24]=2` | `w[6]=5  w[24]=3  w[7]=1` |
| < 8.5 m | `w[4]=8  w[8]=8  w[9]=6  w[12]=10  w[13]=10  w[24]=5` | `w[5]=5  w[24]=10` |
| 贴进模型里（`dist < −3`） | `w[24]=3  w[16]=3` | `w[5]=4  w[24]=3  w[16]=3` |
| 出了正面 90° 扇形 | `w[20]=10`（只转身，不出招） | 同 |

`GetDist` 是从角色原点算、再减去自身 hitRadius 的，所以你贴进模型里它会是负数——最后一行测的就是这个。

两个结构性细节值得注意：

* **半血是硬编码分支，不进权重表。** `GetHpRate() < 0.5` 且身上没有 `16581` → 直接排动画 3014 并
  `return true` 跳出 `Activate`。掷点根本没发生，所以那段转换保证只出现一次。
* **地图区域 5102880**（`自己在这个区域内`时）额外加两手（`w[11]`、`w[19]`），权重只有 1–2。这是场地
  几何渗进 AI 的地方：在坑的某个位置，他多两个选项。

所以冷却中的招是真的抽不到。

## 打断层

`Goal.Interrupt` 只对他**自身**的 SpEffect（5025–5029）激活做反应，也就是动画内部的标记点。每一个都能
清掉当前计划、插一手不同的收尾：

| 自身 SpEffect | 条件 | 插入 |
|---|---|---|
| 5025 | 5 ≤ 距离 ≤ 24 m | 3030 或 3031（各 50%） |
| 5026 | 距离 ≤ 22 m | 3013 |
| 5027 | 距离 ≤ −5（你贴在他身上） | 3001 |
| 5028 | 距离 ≤ −5 | 3018 |
| 5029 | 距离 ≥ 15 m | 3015 |

**没有** `INTERUPT_UseItem`。米狄尔不会因为你喝元素瓶而插招——对比灰烬审判者古达，后者会。

## 这些数字说明了什么

* 近距离除纯位移外每一手都有 30–40 秒冷却，3002/3038 更是 60 秒。近身有十几手可选，压迫感来自
  **表的宽度**，不是"出招快"。
* `> 17 m` 那一档是二阶段真正加料的地方（3011，以及通过 Act 22 用的 3038）——远距离行为变化比近战更大。
* 只要你离开他的正面扇形，权重就变成"只转身"（`w[20]=10`）。这就是为什么你绕背时他不会傻挥：出了 90°
  他先重新瞄准。
* `16571`–`16576` 检查的是**你身上**（`TARGET_ENE_0`）。Paramdex 把这六个全命名成 "Darkeater Midir -
  Bridge"，说明它们是场地脚本贴的战斗专用状态标记，不是中毒出血那种玩家状态。

## 一个保留意见

`GOAL_DarknessDragon621100_Battle_AfterAttackAct` 反编译出来是五个距离分支、每个分支都是空壳。两种可能：
原版确实没有攻击后的间距调整（说得通，他不后撤），或者反编译器把调用丢了。请把"米狄尔没有攻击后间距"
当作这份 dump 的观察，而不是已核实的事实；要用它论证之前先回字节码看一眼。
